# VibeTree

[日本語はこちら](#日本語版)

A customizable directory tree generator for Markdown READMEs—a simple, Python-based alternative to the standard `tree` command.

**Features:**
- **Hide noise:** Completely exclude directories like `__pycache__` or `.venv`.
- **Filter files:** Cleanly filter out any extensions you don't want to see.
- **Safe depth:** Automatically limits the scan to 5 levels deep to prevent output overload.
  
---

**Built with pure vibe and late-night impulse because dealing with unwanted directories in the standard Windows `tree` command was just too much of a hassle.**

"I just want to filter out the garbage, add some neat comments on the right, and make a beautiful tree for my README without accidentally blowing up my terminal!"
This tool was born out of that exact midnight frustration.

---

VibeTree is a Python-based utility that customizes directory outputs, filters out unnecessary folders or file extensions, and appends neatly aligned descriptions (comments) to your files and directories. 

It is the perfect tool for generating clean, professional-looking repository structures to paste directly into your documentation.

## Key Features

- **Configurable Depth Limit (Default Max: 5)**
  Prevents terminal freezes or accidental output flooding by capping the directory traversal to a maximum of 5 levels by default (configurable via settings or arguments).
- **"Folders Only" by Default**
  Keeps things clean. By default, it only maps out your directory structure. Want to include files? Just pass a quick option when running it.
- **Perfectly Aligned Multi-Byte Comments (NEW)**
  Equipped with a custom width-calculation logic that accurately counts full-width Japanese characters as 2 slots and alphanumeric characters as 1. Your comment delimiters (`#`) will align perfectly into a beautiful vertical column, regardless of varying file name lengths.
- **Markdown-Friendly Width Limiter (NEW)**
  To keep your README files readable and prevent horizontal scrolling, the alignment width is capped at a maximum of 80 characters. Any extremely deep-nested lines that exceed this limit will automatically wrap with a minimal padding margin, preserving the overall alignment grid.
- **Absolute Directory Hiding (hide_dirs)**
  Completely wipes noisy folders like `__pycache__` or temporary backups from the tree output.
- **Shallow Directory Exclusion (exclude_dirs)**
  Keeps environment folders like `venv` or `node_modules` visible in the tree by name, but strictly stops the script from drilling down into their massive subdirectories.
- **Automatic Folder Slashes**
  Automatically appends a trailing `/` to directory names, making it instantly clear what is a folder and what is a file.
- **Extension Filtering (exclude_exts)**
  Pinpoints and removes clutter files like `.pyc`, `.DS_Store`, or `.old` from polluting your output.

## Usage

### 1. Requirements

* Python 3.11 or higher
  * Uses the built-in `tomllib` module. No external dependencies are required for Python 3.11+.
  * For Python versions below 3.11, please run `pip install tomli` before execution.

### 2. Configuration Setup

Create a file named `vibe_tree_config.toml` in the same directory as `vibe_tree.py` (or your current working directory) to define your custom settings and comments.

Pre-configured samples for generic, Python, and Node.js full-stack projects are also available in the `examples/` directory. You can copy and adapt them to match your project.

Below is an example of the configuration file based on the root settings:

<details>
<summary>Show / hide vibe_tree_config.toml (click to expand)</summary>

```toml
# vibe_tree_config.toml - General & Minimalist Project Configuration (English)

[settings]
# [Depth Control] Maximum depth limit optimized for a general directory structure
max_depth_limit = 6

# Default depth to display when no depth option is specified
default_depth = 3

# [Complete Hide] Directories and files to completely remove from the tree
# Filters out standard version control folders, editor configurations, and basic caches
hide_dirs = [
    ".git",
    ".vscode",
    ".idea",
    "__pycache__",
    "node_modules"
]

# [Collapse Content] Display the directory name but hide its internal contents
exclude_dirs = [
    "images",
    "img",
    "assets",
    "vendor",
    "backup"
]

# [Extension Exclusion] Exclude specific file types to improve visual clarity
exclude_exts = [
    ".DS_Store",
    "Thumbs.db",
    ".log",
    ".old",
    "*.bak",
    "*.tmp"
]

[comments]
# --- Tool & Common Documents ---
"README.md" = "Project documentation and overview"
".gitignore" = "Git ignore configuration"
"LICENSE" = "Project license agreement"

# --- General Web & Document Structures ---
"index.html" = "Main HTML document (Entry point)"
"style.css" = "Main stylesheet"
"script.js" = "Main JavaScript file"
"docs" = "Directory for internal documentation"
"config.json" = "General project configuration file"

# --- Personal ---
"todo.txt" = "Pending tasks and to-do list"

```

</details>


### 3. Commands

Navigate to your project directory and run the script. Copy the output text directly from your terminal.

```bash
# Basic (Folders only, defaults to the configured depth)
python vibe_tree.py

# Include files in the tree output (Crucial flag)
python vibe_tree.py -f

# Explicitly limit the directory depth (e.g., up to 2 levels)
python vibe_tree.py -d 2

# Temporarily hide comments even if they are defined in your TOML
python vibe_tree.py -nc

# Target a specific external directory and include its files
python vibe_tree.py /path/to/your/project -f

```

## 日本語版

**Windowsの標準`tree`コマンドは愛しているけれど、表示したくないディレクトリ（フォルダ）の扱いが面倒、ということで、バイブスと衝動だけで作成した高機能ディレクトリ（フォルダ）ツリー生成スクリプト。**

「不要なディレクトリを弾きつつ、右側にいい感じのコメントを添えてREADME用のツリーを作りたい、もうディレクトリをよけて、戻さないで起こす事故いや！」
そんな深夜の怒りだけで実装されました。

---

Windowsの標準`tree`コマンドの出力をカスタマイズし、特定のディレクトリや拡張子を除外しながら、各ファイルへの説明（コメント）を付与してツリー構造を出力できるPython製のツールです。

ドキュメント（README等）にプロジェクトのディレクトリ構造を美しく掲載したい場合に最適です。

## 主な機能

- **安全な階層制限（デフォルト最大5階層）**
  予期せぬ大量のファイル出力による画面フリーズや事故を防ぐため、探索する深さを最大5階層までに制限（設定や引数で変更可能）しています。
- **デフォルトは「フォルダのみ」のスッキリ出力**
  標準状態ではフォルダの階層だけをサクッと出力します。ファイルも含めたい場合は、実行時にオプションをつけるだけです。
- **全角対応のスマートなコメント縦揃え（NEW）**
  全角日本語の文字幅（半角2マス分）を厳密に計算するロジックを搭載。ファイル名の長さに影響されることなく、右側のコメント開始位置（ `#` ）が自動で美しく揃います。
- **Markdown崩れを防ぐ幅リミッター（NEW）**
  ツリーが横に長くなりすぎた場合にMarkdownの閲覧性が落ちるのを防ぐため、アラインメントの推奨幅を最大80幅に制限しています。この制限幅をはみ出す極端に深い階層の行は、全体の列を壊さないよう個別にスペースを詰めて出力されます。
- **フォルダの完全非表示（hide_dirs）**
  `__pycache__` や `退避` フォルダなど、ツリー上に存在自体を表示させたくないフォルダを完全に除外します。
- **下層ディレクトリの非表示（exclude_dirs）**
  `venv` や `node_modules` などの環境フォルダにおいて、「フォルダの存在（名前）自体はツリーに残しつつ、その配下の詳細なファイル群（下層）には潜らない」という制御が可能です。
- **フォルダ名へのスラッシュ自動追加**
  ディレクトリであるかファイルであるかを一目で判別できるよう、フォルダ名の末尾に自動で `/` が付与されます。
- **拡張子指定の除外（exclude_exts）**
  `.pyc` や `.DS_Store` など、画面を汚す不要なファイルをピンポイントで除外します。

### 3. コマンドの実行

対象のフォルダ（ディレクトリ）に移動し、以下のコマンドを実行します。出力されたテキストをそのままコピーしてドキュメント等にご活用ください。

```bash
# 基本形（デフォルトではフォルダのみ、3階層まで出力）
python vibe_tree.py

# ファイルもツリーに含めて出力したい場合（重要）
python vibe_tree.py -f

# 階層の深さを指定して実行する場合（例: 2階層まで）
python vibe_tree.py -d 2

# TOMLにコメントが書いてあっても、今回はコメントを隠して出力したい場合
python vibe_tree.py -nc

# 特定のフォルダを対象にして、ファイルも巻き込んで出力する場合
python vibe_tree.py C:\path\to\your\project -f

```
